# IBM-HR-Analytics-Dashboard
Interactive HR Analytics Dashboard built in Power BI .

## Overview
This Power BI dashboard provides insights into employee demographics, workforce distribution, job roles, departments, marital status, and business travel patterns.

## Features
- Employee Age Analysis
- Gender Distribution
- Department-wise Employee Count
- Job Role Analysis
- Marital Status Breakdown
- Business Travel Insights
- Interactive Visualizations

## Tools Used
- Power BI
- Power Query
- Data Visualization
- Business Intelligence
